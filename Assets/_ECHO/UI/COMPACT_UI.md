# Компактный UI ECHO

## Применение
В открытом Unity Editor, вне Play Mode: **Tools → ECHO → Apply Compact UI**.
Команда обновляет существующий EchoUI.prefab, затем сохраняет MainMenu, Level_01 и Level_02.
Игровые объекты и UIEventBridge не пересоздаются; DataProvider каждого уровня проверяется перед сохранением.
Перед запуском предлагается сохранить незаписанные изменения сцен.

## Canvas
Сохранён один существующий Canvas и CanvasScaler (1920×1080, масштаб по высоте).
- HUD: прозрачный счётчик всех сохранённых Эхо слева; время цикла справа; существующие прицел и подсказка взаимодействия.
- Compact timeline: шкала шириной 680 UI-единиц, маркер времени и дочерний контекстный индикатор записи.
- Notification: временное сообщение; обучение клавишам показывается один раз за сеанс редактора/приложения.
- Scanner HUD: данные сканера при его использовании; состояния узлов во время сканирования/активного резонанса.
- Timeline: полупрозрачная панель снизу по центру, высота по реальным дорожкам, максимум 40% высоты Canvas, затем ScrollRect.
- Существующие меню сохранены; в меню паузы добавлена справка по клавишам.

Запись и цикл сохраняют разные расчёты: общий прогресс = Time/Duration; интервал записи = [RecordStart/Duration, RecordEnd/Duration].
Состояния и реальные интервалы Эхо остаются в Timeline. Сканирование выделяется верхними узкими сегментами, движение — обычными сегментами.
Счётчик использует Echoes.Count и Capacity, а не число копий в состоянии Playback.
Публичные поля старого списка и CompactTime сохранены ради совместимости; новый prefab не создаёт эти объекты.

## Изменённые исходники
- Editor/EchoUIBuilder.cs — сборка компактного UI и безопасная команда применения.
- Scripts/UI/HUD/EchoStatusUI.cs — счётчик без списка, короткий импульс при увеличении.
- Scripts/UI/HUD/CycleTimerUI.cs — только текущее время.
- Scripts/UI/HUD/HUDController.cs — устранение дублирования времени, короткие уведомления, однократное обучение.
- Scripts/UI/HUD/RecordingIndicatorUI.cs — контекстная видимость и независимый интервал записи.
- Scripts/UI/HUD/ScannerHUD.cs — контекстная видимость фазовой информации.
- Scripts/UI/Timeline/TimelineUI.cs — высота по содержимому, ограничение и прокрутка.
- Scripts/UI/Timeline/TimelineTrackUI.cs — форма сегментов сканирования и отметки F-взаимодействия.
- Scripts/UI/Core/UIManager.cs — подписка Timeline на существующие InteractionOccurred/CycleRestarted, с отпиской при уничтожении.
- Editor/Level01Validation.cs — команда compact для существующего локального Editor-harness.
- UI/README.md — ссылка на актуальную структуру и отчёт; создан UI/COMPACT_UI.md и его .meta.
- Tests/PlayMode/UITests.cs — проверки компактного HUD, переполнения Timeline, разрешение 3440×1440.

Изменены UI/Prefabs/EchoUI.prefab, EchoStatusRow.prefab, TimelineTrack.prefab; TimelineSegment.prefab пересохранён без содержательных изменений. Сохранены Scenes/MainMenu.unity, Scenes/Levels/Level_01.unity и Level_02.unity. Обновлены Tests/Results/EditMode.xml и PlayMode.xml. Ранее существовавшие пользовательские изменения материалов, игровых скриптов и PNG сохранены.
Новых менеджеров, Canvas, сторонних зависимостей и игровых контроллеров нет. Файлы не удалялись.

## Сохранённые контракты
UIEventBridge, UISnapshot, IUIDataProvider и IUICommands остаются источником игровых данных.
GameManager продолжает управлять паузой и timeScale. Tab, курсор, события взаимодействия, запись и воспроизведение не изменены.
Raycast UI не добавлялся. Цвет прицела поступает из прежнего взаимодействия/сканера.

## Ограничения
Существующая система не сохраняет и не воспроизводит F-взаимодействия в записи Эхо. Timeline показывает доступные реальные F-события игрока в текущем цикле; эти отметки очищаются при новом цикле. Интервалы сканирования Эхо берутся из прежних записанных ScanFrame.
Игровая дорожка, как и прежде, отображает интервал текущей записи; подробная сегментация движения/ожидания/сканера строится для сохранённых Эхо.
Отдельный Windows Player не собирался; проверки выполнены в открытом Editor/Play Mode.
